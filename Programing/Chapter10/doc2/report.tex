\subsection*{如何使用}
在code中build文件下使用make命令编译，编译成功后，在build文件夹下会生成可执行文件main,在test目录下的main.json调整初始条件即可使用不同的测试用例。

在文件EquationSolverFactory.h中，设计了工厂模式以及单例模式，为选择不同的求解器提供了方便。

\begin{lstlisting}[language=C++]
{
    "FuncName" : "Func",
    "method" : "AB4",
    "output_file" : "output",
    "condition_type" : 1,
    "step" :200000,
    "print_accurate" : false,
    "is_test" : false
}
\end{lstlisting}

\begin{enumerate}
    \item method选择不同的方法与精度
    \item conditiontype选择不同的初始条件
    \item step选择不同的步数
    \item print\_accurate选择是否打印数值精度
    \item is\_test选择是否进行测试
\end{enumerate}

注意，使用AB，AM，BDF，GLRK方法时需要指定精度，否则会报错；反之使用CRK，ESDIRK，
Feldberg，Dormand-Prince方法时不需要指定精度，否则会报错。

\subsection*{总结}
收敛情况最好的是Gauss-Legendre RK方法，但是缺点是计算时间数，这跟步数有关，也跟我使用newton迭代求解时
使用的初始值不够精确有关。

Feldberg方法和Dormand-Prince方法的计算时间最少，因为他使用的步数最短，只有一百步，但是因为规定了$\rho_{min}$最
小不得少于0.2,所以导致画出来的图片不够光滑，误差也比较大。

其他的方法表现中规中居，我觉得能兼顾收敛速度和精度，是经典RK方法。
