Numerical Analysis

2024-2025秋冬学期数值分析课程（王何宇）
本仓库中主要语言类型包括：

    C++
    Latex


使用说明

    Project：
        \bin：存放编译后的可执行文件
        \src：存放源代码文件
        \doc：存放文档文件
        \figure：存放图片文件

    在Chapter3文件下在终端输入make命令即可编译并运行src中的ProblemA,ProblemC,ProblemE,ProblemF,图片被输出在figure中，同时编译doc中的tex文件，tex文件中的所有图片均可在figure中找到。
